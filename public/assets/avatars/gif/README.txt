Dépose ici tes fichiers .gif : ce seront les avatars "GIF" proposés aux
joueurs en plus des emojis (nouvel onglet "GIF" dans le choix d'avatar).

Règles :
- Extension .gif obligatoire (tout le reste est ignoré).
- Le nom du fichier SANS l'extension devient le nom affiché/interne de
  l'avatar (ex. poulet-dansant.gif -> "poulet-dansant"). Choisis des noms
  clairs, sans espace ni caractère spécial de préférence.
- Aucun redémarrage du serveur nécessaire : la liste se recharge à chaque
  fois qu'un joueur ouvre l'écran de choix d'avatar.
- Pas de taille limite imposée côté code, mais reste raisonnable (quelques
  centaines de Ko par GIF) pour ne pas ralentir le chargement des joueurs.
